# 1. MapKit이 무엇일까

Apple 플랫폼에서 지도 기능을 앱을 추가하기 위해 사용하는 프레임워크 이다.

Core Location과 달리 위치를 지도위에 보여주는 역할이다.

### 단순히 지도를 앱에 띄우는게 아니다.

* 이동, 확대 및 축소, 장소 표시, Marker와 Annotation 표시 등의 지도 관련기능을 제공



# 2. MapKit은 어떤 상황에 주로 사용할까

지도 자체가 필요할때 MapKit을 사용한다.

* 배달 앱에서 배달 위치를 표시할때
* 맛집 앱에서 식당 위치를 표시할때
* 현재 위치를 지도 위에 표시할때
* 등등

여기서 잊으면 안되는것이 MapKit은 지도를 표현하는것이다.(**위치를 측정하는게 아님**)


# 3. 지도 앱에서 MapKit이 하는 역할

지도와 관련된 UI와 지도 표현을 담당한다.

```
여기서 CoreLocation이 사용자의 위치가 어떤 위도와 경도인지 알아내면 MapKit
대신 쓸수 있는거 아닌가 라고 생각하지만 그 값은 숫자에만 불과해서 불가능하다.
```

### MapKit은 좌표를 이용하여
* 지도 화면 -> 해당 위치로 이동
* 해당 위치에 Marker 표시
* 특정 범위 화면에 표시

### 한마디로 
* MapKit = 해당 위치를 지도에서 어떻게 보여줄 건가
* CoreLocation = 사용자가 어딨는가


# 4. MKMapView

UIKit에서 지도를 표시할때 사용하는 지도UI 클래스 이다.

#### MKMapView로 이런 작업들이 가능
* 지도 표시
* 특정 위치로 이동
* 지도 스크롤
* 지도 중심 변경
* 사용자 위치 표시
* 특정 지역 표시
* 등등

쉽게 생각 하면 UIKit에서 UI를 UIView 계열의 객체로 표현하기에 **지도 화면을 담당하는 View**라고 생각하면 쉽다.


# 5. SwiftUI에서의 Map

MapKit에서 제공하는 Map을 사용해서 UI를 구현 가능

#### Map 에서 지도와 함깨
* Marker
* Annotation
* UserAnnotation

등을 선언적으로 배치 가능

```
한마디로

SwiftUI = Map
UIKit = MKMapView
```


# 6. CLLocationCoordinate2D

지구 위의 특정 위도와 경도를 표현하는 구조체 이다.

#### 구성으로
* latitude = 위도
* longitude = 경도

하나 알아둬야는게 CLLocationCoordinate2D는 위도와 경도를 하나의 위치로 표현하는 자료형일 뿐이지 직접 위치를 측정하는것이 아니다.


# 7. latitude

지구에서 북쪽과 남쪽 위치를 나타낸다.

적도가 기준으로, 북쪽으로 갈수록 양수, 남쪽으로 갈수록 음수로 취급한다.

```
한마디로
latitude = 위아래의 위치
```


# 8. longitude

지구에서 동쪽과 서쪽 위치를 나태낸다.

본초 자오선을 기준으로 한다

```
한마디로
longitude = 좌우 위치
```


# 9. CLLocationCoordinate2D vs CLLocation

* CLLocationCoordinate2D
 위도와 경도를 가져 단순히 자표 자체를 표현하는 자료형이다.

* CLLoction
좌표뿐만이 아닌 위치 측정과 다양한 자료를 얻을수 있음

예시로
```
좌표
정확도
이동 속도
이동 방향
시간
```
한마디로 

CLLoctionCoordinate2D = 위치 좌표

CLLocation = 위치 측정 결과


# 10. MKCoordinateRegion

지도에서 어느 화면을 보여줄지 나태내는 영역이다.

* center
지도의 중심 위치를 가진다.


* span
중심을 기준으로 얼마나 넓은 범위를 보여줄지 나타낸다.
  #### 대표적으로 
  * latitudeDelta
  * longitudeDelta

  ### span의 크기
  크면 클수록 넓은 범위를 보여줌 다만 작을수록 작은 범위를 보여준다


# 11. region
지도 화면에서 보여주는 지리적 영역 이다.

#### region에는
* 지도 중심
* 지도에서 보여줄 범위
가 포함된다

즉 화면을 이동한다 -> 지도에서 보여주는 region을 변경


# 12. Marker

지도에서 특정 위치를 표시하기 위한 마커이다.

예시로
```
학교
식당
목적지
```
이처럼 특정 위치를 표시할때 사용한다.

# 13. Annotation

지도에서 특정 위치를 묘시할때 사용한다.

다만 Marker보다 더 자유롭게 UI사용이 가능하다.

예시로
```
사용자 프로필 사진
학교 아이콘
식당 로고
가격 정보
직접 만든 SwiftUI View
```

# 14. Marker vs Annotation

| 구분 | Marker | Annotation |
| --- | --- | --- |
| 목적 | 기본 위치를 표시한다. | 사용자 정의의 위치를 표시한다. | 
| 디자인 | MapKit의 기본 UI이다. | 직접 만든 UI에서 사용이 가능하다. |
| 난이도 | 간단해서 쓰기 쉽다. | Marker보다 사용이 자유롭다. |

#### 한마디로
```
Marker = 단순한 위치 표시
Annotation. = 직접 디자인한 지도 UI
