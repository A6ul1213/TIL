# MapKit이 무엇일까

Apple 플랫폼에서 지도 기능을 앱을 추가하기 위해 사용하는 프레임워크 이다.
Core Location과 달리 위치를 지도위에 보여주는 역할이다.

### 단순히 지도를 앱에 띄우는게 아니다.

* 이동, 확대 및 축소, 장소 표시, Marker와 Annotation 표시 등의 지도 관련기능을 제공



# MapKit은 어떤 상황에 주로 사용할까

지도 자체가 필요할때 MapKit을 사용한다.

* 배달 앱에서 배달 위치를 표시할때
* 맛집 앱에서 식당 위치를 표시할때
* 현재 위치를 지도 위에 표시할때
* 등등

여기서 잊으면 안되는것이 MapKit은 지도를 표현하는것이다.(**위치를 측정하는게 아님**)
