# 열거형(Enumeration)
공통된 주제에서 이미"정해둔 입력값"만 선택해서 받고 싶을때 사용

### 원시값이 없는 열거형
* 한마디로 "열거형 이름만 써서 선언"하는 것이 원시값 없는 열거형임
* 내가 서언한 열거형 타입은 **.을 사용해서 접근 가능**

```Swift
enum Position {
  case top
  case mid
  case jug
  case adc
  case sup
}
```
이것처럼 case로 다 써서 나열도 가능하고

```Swift
enum Position {
  case top, mid, jug, adc,sup
}
```
이렇게 한 case에 나열해도 됨

### 원시값이 있는 열거형
위에서 case를 지정할때 아무것도 대입하지 않았지만 여기에도 원시값을 지정해줄수 있는데 이것을 **Raw Value**라고함
```Swift
enum Position: Int {
  case top       //0
  case mid       //1
  case jug       //2
  case adc       //3
  case sup       //4
}
```
이렇게 앞에 Int라는 타입을 달면 가장 먼저 선언된 case는 **0부터 1씩 증가하는 값**이 들어감
```Swift
enum Position: Int{
  case top = 0       //0
  case mid = 10      //10
  case jug           //11
  case adc = 20      //20
  case sup           //21
}
```
이런식으로 RawValue값을 지정할수도 있음
* 주의 할점
Int같이 정수만 들어가야 하는 타입을 선언했을경우 모든 case 값을 지정해 주는것이 아니라면 Double같은 타입을 지정해 줄수 없다.)

### Character Type을 가지는 열거형
```Swift
enum Position: Int {
  case top = "t"     //t
  case mid = "m"     //m
  case jug = "j"     //j
  case adc = "a"     //a
  case sup = "s"     //s
}
```
* 주의 할점
Character Type으로 열거 할경우 모든 case에 RawValue로 직접 선언해야함

### String Type을 가지는 열거형
String은 Character 와 달리 RawValue 지정을 하지 않으면 case 이름 과 동일한 RawValue가 만들어짐
```Swift
enum Position: Int {
  case top       //top
  case mid       //mid
  case jug       //jug
  case adc = "slave"     //slave
  case sup       //4
}
```
이렇게 case 뒤의 값이 들어가게 됨
