# 참조타입 , Heap
* 스택에 있는 함수는 인스턴스를 참조 하고 형태로, 힙 안에 할당된 **인스턴스 주소값**이 들어가 있다.
* 클래스로 지정한 **인스턴스**는 **힙**에 해당한다.

# ARC(Automatic Reference Counting)
메모리의 영역중 **힙**의 영역을 관리하는것으로, 힙에 자동 할당되여 사용해 왔음
* 힙 같은 경우 끌떄 메모리를 해제 시켜줘야 하지만 ARC는 클래스 인스턴스가 더 이상 필요없다고 판단할 경우 자동으로 해제 시킴

# GC(Garbage Collection) vs Rc(Reference Counting)
### 계산 시점,장점,단점
* **GC**
```
Run Time
-> 어플 실행 동안 주기적으로 사용되지 않는 istance를 찾아 해제 시킴

장점 : 인스턴스가 해제 될 확률이 높음
-> 인스턴스를 해제 하면 메모리를 제사용할수 있고, 메모리 누수를 막을수 있으며, 앱이 안정적으로 돌아감

단점 : 참조 해제 시점을 정확히 알수 없고 인스턴스를 추적하는 과정에서 성능 저하가 발생 할수 있음
```

* **RC**
```
Complie Time
-> 컴파일 시점이 언제고 언제 해제 되는지 결정 뒤 Run Time시점 뒤 실행

장점 : 참조 해제 시점을 파악 가능하고 Run Time 시점에 추가 리소스가 발생하지 않음

단점 : 영구적으로 메모리 해제가 되지 않을 가능성도 있음
```

# ARC의 메모리 관리
메모리의 RC(참조 회수) 계산후 0 이 되면 사용 하지 않는걸로 판단하고 메모리를 해제함.
모든 인스턴스는 RC를 가져 모든 인스턴스가 해당됨
