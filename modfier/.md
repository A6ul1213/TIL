# Modifer
view의 모양,크기,색상 등의 속성을 변경하고 스타일을 적용하는 메서드

# Modifer 적용 순서

### 원리
**Modifer는 기존의 view 에 modifer를 적용하여 새로운 view를 만들고 리턴** 함
modifer가 추가될수록 modifer이 view를 감싸서 새로운 modifer를 적용해 리턴하는 행위가 반복됨

#Tip
modiferd의 순서에 따라 완전히 다른 뷰가 탄생할수도 있음

```swift
vStack {
  Button("Button 1") {
    print(type(of: self.body))
}
  .frame(width: 150, height: 150)
  .background(.yellow)

  Button("Button 2" {
    print(type(of: self.body))
}
  .background(.yellow)
  .frame(width: 150, height: 150)

}
```
