# 싱글톤 패턴(Singleton Pattern
* 특정 용도로 객체를 하나 만들었는데 이걸 공용으로 사용하고 싶을때 쓰는 디자인 유형
* 즉 한 Istance에서 어느 클래스든 접근가능하게 하는것임

이런식으로 이해하면 좋다.

# Singleton Class 만드는 법
1.  static프로퍼티로 Instance 생성
2.  init 함수 접근 제어지를 private로 지정
다만 init함수를 호출하여 Instance를 또 생성 해버리는 불상사를 막기 위해서 init() 함수 접근 제어자를 **private**로 지정하면 좋다.

# Singleton Class 접근 법
* 매우 시운데 아까 생성했던 static 프로퍼티를 사용하면 된다.
어느 클래스든 **shared**란 **static 프로퍼티**로 접근 하면 하나의 Instance를 공유허는 꼴이 된다.

# Singleton 장단점
#### 장점
1. 한번의 Instance만 해도 되기때문에 메모리 낭비 방지
2. 전역 Instance라 다른 클래스들과 자원 공유가 쉬움
3. 공통된 객체를 여러개 생성해야하는 상황에서 많이 사용

#### 단점
1. 한개의 Instance로 너무 많은 양이 진행되면 다른 클래스의 Instance둘과의 결합도가 너무 높아져서 원칙을 높아지게 됨
2. 위의 이유로 수정이 힘들어짐
