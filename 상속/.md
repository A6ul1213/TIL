# 상속(inheritance)
오로지 "Class"만 상속이 가능하며, 상속은 단일 상속만 허용함(다중 X)
Class, 프로퍼티 및 기타 특징들을 상속

### 1. 기본 클래스(Base Class)
아무 Class도 상속 받지 않은 클래스
* Class 이름 뒤에: 하고 먼저 나오는것 중 클래스가 아니면 "기본 Class"

```swift
class Human: Hashable {
  var name: String?
  var age: Int?
}
```
여기서 Hashable 은 프로토콜임

### 서브 클래싱(subclassing)
기본 Class를 이용하여 새 Class를 만드는 작업이다.
* 서브 Class 옆에 : 을 쓰고 가장 먼저 상속 받을 슈퍼 Class의 이름을 적기
* 예를 들어 Human이란 클래스를 **Teacher 클래스**에 상속 시키려고 하는것을 **서브 클래스(Sub Class)** 라고 부름
* 여기서 상속 받고자 하는 클래스를 슈퍼 클래스(Super Class), 상속 받는 클래스를 서브 클래스(Sub Class)라고 함

```swift
class teacher: Human{
  var subject: String?
}
```
Class 선언시 이렇게 : 뒤에 첫번째로 상속할 Class의 이름을 작성하면 됨

### final ::  상속을 금지
클래스에 상속을 원하지 않을 경우 **"final"** 이란 키워드를 사용

```Swift
final class Human {
  var name: String?
  var age: Int?
}
```
이렇게 Class앞에  **"final"** 을 붙이면 아무도 그 클래스를 상속 받지 못함
