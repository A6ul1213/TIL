# UIKit
Appple이 제공하는 iPhone/iPad 앱의 UI를 만드는 프레임 워크 이다.

```
텍스트          UILabel
버튼            UIButton
이미지          UIImageView
입력창          UITextField
화면            UIView
화면 관리자      UIViewController
목록            UITableView
격자 목록        UICollectionView
화면 이동        UINavigationController
탭              UITabBarController
```
