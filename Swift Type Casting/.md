# 타입 캐스팅(Type Casting)
런타임 타입을 확인하거나, 더 구체적인 타입 정보로 좁히는것

### 사용 이유
1. **타입 확인**: 지금 값이 어떤 타입인지 검사
2. **타입 변화(케스팅)**: 더 구체적인 타입으로 취급

# 4개의 타입 캐스팅 연산자(is/as/as?/as!)

### -is : 분기 조건에서 가장 안전한 타입 체크
타입 체크 (결과는 Bool)
is는 "이 값이 특정 타입(or 프로토콜)을 만족하는지 검사

### -as : 업캐스팅(항상가능) 또는 브리징
업캐스팅/브리징 처럼 "항상 가능한" 캐스팅이다. 

### -as? : 다운캐스팅(실패가능, 옵셔널)
실패할수도 있는 다운캐스팅 (옵셔널 변환)
부모 타입을 자식으로 내리는것을 실패할 가능성이 있다.

### -as! : 강제다운캐스팅
강제로적인 캐스팅으로 확실할때만 사용해야한다.
즉 논리적으로 "절대 실패 하지 않는다"라는 전제가 있을때 사용한다.
