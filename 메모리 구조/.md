## 코드 영역
* **소스코드**가 **기계어 형태**로 저장 됨 컴파일 타임에 의해 결정 
* **Read-Only** 형태로 저장되어 코드가 변경 되지 않게 함

## 데이터 영역
* **전역변수**,**static** 변수로 지정
* 프로그렘 **시작과 동시에 할당** -> 종료시 **메모리 해제**
* **Read-Write**형태로 도중에 코드 변경 가능

## 힙 영역
* 프로그레머가 할당/해제 할때 사용
* **malloc**,**calloc** 등으로 메모리 할당 가능 -> 동적 할당
* 사용후 **메모리 해제**를 해야하고 하지 않을 경우 **memory leak**현상 발생
* 런타임시 결정되므로 **데이터 크기가 확실하지 않을때** 사용

```### 장단점
#### 장점
---
* 메모리 크기 제한 X
* 본질적인 범위가 전역이라 모든 함수 엑세스 가능

#### 단점
---
* 할당/해제 작업,힙 손상시 속도 저하
* 메모리 관리를 직접
```

## 스택 영역
* **함수 호출**시 **지역 변수**,**매개 변수** 등 저장
* 함수 종료시 메모리 해제
* **컴파일 타임** 결정 때문에 무한히 할당 가능
