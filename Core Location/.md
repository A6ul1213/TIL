# Core Location
Apple 플랫폼에서 기기 위치 및  이동 관련 정보를 얻기 위한 프레임 워크 이다.

여러 정보를 활용하여 기기의 위치를 판단할수 있다.

->Core Location은 사용자의 기기가 어딨는지 알아내기 위한 프레임 워크

# Core Location의 사용법
이동 정보,현재 위치 등을 알아야 하는 상황에서 이 기능을 사용

```
현재 위치 확인
내 위치 공유
목적지 까지 거리 계산
등등
```

# MapKit vs Core Location

| 구분 | MapKit | Core Location |
| --- | --- | --- |
| 목적 | 지도 | 위치 |
| 역할 | 지도 화면 표시 | 위치 정보 획득 |

한마디로
```
Core Location = 위치를 구하고
MapKit =  위치를 확인
```

# CLLocationManger

Core Location에서 위치를 관리하는 핵심 객체

GPS를 조작하는 것이 아니라 CLLocationManger를 통해 위치 정보를 요청한다.

```
위치 업데이트 시작
위치 업데이트 중지
위치 한 번 요청
위치 정확도 설정
거리 필터 설정
위치 권한 상태 확인
```

CLLocationManger = 위치 서비스를 관리하고 요청하는 객체 (관리자)
