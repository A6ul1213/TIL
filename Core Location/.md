# 1. Core Location
Apple 플랫폼에서 기기 위치 및  이동 관련 정보를 얻기 위한 프레임 워크 이다.

여러 정보를 활용하여 기기의 위치를 판단할수 있다.

->Core Location은 사용자의 기기가 어딨는지 알아내기 위한 프레임 워크

# 2. Core Location의 사용법
이동 정보,현재 위치 등을 알아야 하는 상황에서 이 기능을 사용

```
현재 위치 확인
내 위치 공유
목적지 까지 거리 계산
등등
```

# 3. MapKit vs Core Location

| 구분 | MapKit | Core Location |
| --- | --- | --- |
| 목적 | 지도 | 위치 |
| 역할 | 지도 화면 표시 | 위치 정보 획득 |

한마디로
```
Core Location = 위치를 구하고
MapKit =  위치를 확인
```

# 4. CLLocationManger

Core Location에서 위치를 관리하는 핵심 객체

GPS를 조작하는 것이 아니라 CLLocationManger를 통해 위치 정보를 요청한다.

```
위치 업데이트 시작
위치 업데이트 중지
위치 한 번 요청
위치 정확도 설정
거리 필터 설정
위치 권한 상태 확인
```

CLLocationManger = 위치 서비스를 관리하고 요청하는 객체 (관리자)


# 5. CLLocation

시스템이 측정한 하나의 위치 정보를 나타내는 객체

단순히 위도/경도 만 포함된게 아닌 여러 정보를 포함 가능하다.


# 6. CLLocation에 어떤 정보가 있는가

* coordinate = 위도/경도
* altitude = 고도
* horizontalAccuracy = 수평 위치 정확도
* verticalAccuracy = 고도 정확도
* speed = 이동 속도
* course = 이동 방향
* timestamp = 위치가 측정된 시간
* 등등

즉 단순 좌표보다는 위치를 측정한 결과 데이터 라고 생각하면 됨


# 7. CLLocationManagerDelegate

CLLocationManager에서 발생한 결과나 변화를 받는 Delegate이다.

```
CLLocationManager
-> 위치 작업 수행

CLLocationMangerDelegate
-> 위치 작업의 결과를 받음
```


# 8. 위치 정보에서 사용자 권한이 필요한 이유

위치 정보 자체가 매우 중요한 개인 정보임

```
사용자 집
학교
이동경로
등등
```
등을 다 추적이 가능하다. 그렇기에 시용자가 직접 권한을 허용해야한다.


# 9. 위치 정확도

위치 정보는 항상 정확한 하나의 지점을 의미하는 것은 아님

horizontalAccuracy를 사용하면 불확실한 좌표의 범위를 미터 단위로 가능하다

즉 일반적으로 값이 적을수록 더 정확한 값이라고 알수있다.


# 10. 위치를 지속적으로 받아오는것 vs 한번만 받아오는것

* 한번만 위치가 필요한 경우
ex ) requestLocation()

* 계속 위치가 필요한 경우
ex ) startUpdatingLocation()


# 11.  위치 권한

CLAuthorizationStatus로 확인 가능

### notDeterMined
아직 사용자가 위치 권한을 결정하지 않은 상태 및 허용도 하지 않은 상태

-> 허용도 안함, 거부도 안함

### restricted
시스템  정책이나 제한으로 위치 서비스가 사용할수 없는 상태

### denied
사용자가 앱의 위치를 거부하거나 위치 서비스가 꺼져있는 상태

### authorizedWhenInUse
사용자가 앱 사용하는 동안 위치 접근을 허용한 상태

### authorizedAlways
앱을 직접 사용하지 않아도 위치 관련 기능을 사용 가능한 상태(백그라운드에서도 사용 가능)

# 위치 정확도와 베터리

### desiredAccuracy
CLLocationManger에게 어느정도의 정확도가 필요한지 알려주는 값 이다.

ex) 날씨 앱과 네비게이션의 위치 정확도가 다름

### 위치 정확도가 높을수록 좋은가
결과적으로 항상은 아니다.

높아질수록 -> 정확한 위치를 얻을수 있음(다만 더 많은 시스템 자원 사용)

한마디로 필요하지도 않은데 높은 정확도를 사용하여 시스템 자원을 낭비 할수도 있음

### 배터리 사용량
일반적으로 높은 정확도를 요청 할수록 배터리 사용량이 올라간다.

특히
```
높은 위치 정확도 + 지속적인 위치 업데이트
```
전력 소모가 커질수 있기때문에 필요한 만큼의 정확도만 요청하자

### distanceFilter
사용자가 최소 얼마나 이동했는지를 알고 새로운 위치를 업데이트 받을것인지 설정하는 값이다.

ex) distnaceFilter = 100

-> 100m 이동시 새로운 위치 업데이트
