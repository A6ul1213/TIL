# 옵셔널 바인딩(Optional Binding)
Optional Unwrapping 중 하나로, 안전하게 Optional 값을 Unwrapping 할수 있음

### if let
  **메커니즘**
  1. 표현식이 nil인지 판별
  2. 표현식이 nil이 아닌경우 값을 Unwrapping 한 값을 재 대입한다.
```Swift
if let nonOptionalNum = optionalNum {
  print(nonOptionalNum)
} else {
  print(optionalNum)
}

// 이렇게 nonOptional 이란 값이 nil이 아니기 때문에 Unwrapping 한 값을 optionalNum에 대입함
```
  **주의할점**
  1. if let으로 선언된 함수는 scope if 구문이다.즉 상수 접근이 안된다.
  2. 그져 nonOptional은 opptionalNum 을 Unwrapping 한것일뿐 Optional Type임

### guard let
함수에서만 쓸수 있고 guard 구문을 만족 못할시 else문으로 빠져 실행 종료를 시킬때 사용(return)다만 else에서 사용 못함
**메커니즘**
1. 표현식이 nil이 아닌지 확인
2. 표현시기 nil이 아닌 경우 else로 빠지지 않고 guard문을 실행시키던 scope로 돌아옴


## 위 명령어의 공통점
1. 옵셔널 표현식을 먼저 평가
2. 값이 있는 경우 (nil이 아닌경우)는 정의된 함수에 Optional이 Unwrapping 된 값을 저장하고 true를 반환
3. 값이 없는 경우(nil인 경우) false를 반환
4. 타입 추론이 되기때문에 Type Annotaion은 대부분 생략
