# 함수

## 1. 함수 vs 메서드

### 함수
``` Swift
func doSomething() {
  print("Somaker")
}
```
이렇게 func 키워드로 생성되는것은 모두 함수이다.

### 메서드
**클래스, 구조체, 열거형** 속에 포함된 함수
```Swift
class Sodeul {
    func doSomething() {
      print("Somaker")
  }
}
```
만약 func로 선언된 함수가 **클래스, 구조체, 열거형** 속에 있으면 그건 메서드임

## 함수 vs 클로저
클로저는 **Named Closure** 과 **Unnamed Closure** 로 나뉜다
* Named Closure
```Swift
func doSomething() {
  print("Somaker")
}
```
보통 그냥 함수라고 부르지만 클로저임

* Unamed Closure
```Swift
let closure = {print("Somaker")}
```
익명함수라고 부른다 보통 우리가 Closure라고 부르는건 보통 익명함수이다.
