# 옵셔널(Optional)
어떤 변수의 값이 있을수도 있고 없을 수도 있는 임의적인 상태
* 기호로는 ?이다.
```Swift
var test: Int
test = nil//Int
```
이 코드에서 해당 타입의 어떤값을 추가하지 않아 에러가 뜬다. 특히 Int형으로 선언된 변수 test에 nil 값을 넣었기에 더욱 그렇다.
**이떄 사용되는것이 옵셔널 이다.**

```Swift
var test: Int?
test = nil
```
변수 뒤 ?를 붙여 **정수값이 있을수도 혹은 없을수도**라는 경우를 줘서 오류가 뜨지 않는다.

# 옵셔널의 래핑 (Wrapped)
옵셔널 래핑은 값이 있을수도 혹은 없을 수도(nil) 상태를 상자로 감싸는 표현이다.
```Swift
var test: Int? = 10
var answer = test
```
이 코드는 answer이란 값이 옵셔널 타입이 되어 Int형의 값이 있을수도 혹은 없을수도 있는 경우가 된것이다.
**하지만**

```Swif
var test: Int? = 10
var answer: Int = test
```
이렇게 옵셔널타입으로 선언된 test를 Int 타입으로 선언된 answer에 다시 넣으려 하면 오류가 나온다.

# 옵셔널의 언래핑(Unwrapping)
값을 래핑으로 옵셔널 값을 포장하고 옵셔널 값을 조작하면 에러가 뜬다. 그렇기에 옵셔널 타입의 값이 nil이 아니고 그안에 든값을 빼놓기 위한 작업이 언래핑(Unwrapping)이다.
* 안전한 방법:
  1. 옵셔널 바인딩(Optional Binding)
  if 문을 이용하여 옵셔널에 해당한 값이 안전한지 확인하고 임시 변수 또는 상수를 할당 해주는 방식이다.
  2. 옵셔널 체이닝(Optional chaining)
  
  
* 안전하지 않은 방법:
  1. 강제 언래핑(Force Unwraaping)
  **옵셔널 값에 !**를 붙이면 됨 그러면 안에 값이 있든 없든 상자를 찢고 나온다.
  다만 nil 값에 접근하여 조작하는것이기 때문에 런타임 에러가 뜰수 있다.
  2. 암시적 언래핑 (Implicitly unwrappped optionals)
     암시적 언래핑은 강제 언래핑과 동일하게 !를 사용하고 강제적으로 찢고 나오지만 **옵셔널 값이 아닌 옵셔널 타입 뒤**에 !를 붙인다.
     즉 뚜겅이 열린 상자다.
