# 타입 추론(Type Inference)
```Swift
let name = "Seouen
```
초기값을 지정해줌
## 장점
* 선언과 동시에 컴파일러가 초기화된 값을 보고 타입을 추론 해버림 그렇기에 간단함
## 문제점
* 원하는 타입이 추론되지 않을수도 있음
* 초기값이 없을 경우 사용할수 없음
이런 문제점 발생시 타입 어노테이션(Type Annotation)을 사용

# 타입 어노테이션(Type Annotation)
```Swift
let name: String
```
직접 자료형을 지정해줌
## 장점
* 타입 추론으로 원하는 자료형을 얻지 못할 결우 사용이 가능함
* 초기 값이 없을 경우 사용할수 있음
* 타입을 알려줘서 초기 값을 유추할 필요가 없음(시간 단축)
## 단점
* 타입 추론이 가능한경우 코드가 길어질수 있음
